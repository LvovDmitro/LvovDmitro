## Selected work

### [SCFR · Source-Causal Finding Router](https://github.com/LvovDmitro/SCFR)

**NeurIPS 2026 · Main Track · accepted poster**

How should a radiology model use a patient's previous examinations? SCFR controls the influence of historical context on new reports and selects among source-valid report proposals without a reference report at inference. The release provides separate fitting, inference, and evaluation interfaces, runnable CPU demos, and documented release verification.

[Code & demos](https://github.com/LvovDmitro/SCFR) · [Paper](https://openreview.net/forum?id=GHvYdC6tmg) · [Conference page](https://neurips.cc/virtual/2026/poster/154092)

### [LogitGaze · Human attention meets vision–language models](https://github.com/LvovDmitro/LogitGaze)

Predicting where people look by combining transformer-based scanpath prediction with semantic features extracted from a vision–language model. The research extends from visual search to medical imaging through **LogitGaze-Med**, published in the **NeurIPS 2025 Main Track**.

[Code](https://github.com/LvovDmitro/LogitGaze) · [LogitGaze paper](https://openreview.net/forum?id=Om4j6IVb42) · [NeurIPS 2025 paper](https://proceedings.nips.cc/paper_files/paper/2025/hash/be7bc8aa38696723cebe296b6122d7e3-Abstract-Conference.html)
