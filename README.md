Researcher at [Med AI Lab, Innopolis University](https://ilya-pershin.com/lab/).

I work on medical imaging, human attention and the evaluation of clinical models. My first-author papers include LogitGaze-Med at NeurIPS 2025 and SCFR, accepted to NeurIPS 2026. I also work with students on research design, code and experimental results.

[![Email](https://img.shields.io/badge/Email-d.lvov%40innopolis.ru-0F766E?style=flat-square)](mailto:d.lvov@innopolis.ru)

## Selected work

### SCFR

Controls how previous examinations affect a new radiology report. SCFR selects among report candidates without using a reference report at inference. The code includes CPU demos and separate fitting, inference and evaluation commands.

[![Code](https://img.shields.io/badge/Code-GitHub-334155?style=flat-square&logo=github&logoColor=white)](https://github.com/LvovDmitro/SCFR) [![Paper: NeurIPS 2026, accepted](https://img.shields.io/badge/Paper-NeurIPS_2026_%C2%B7_accepted-0F766E?style=flat-square)](https://neurips.cc/virtual/2026/poster/154092)

### LogitGaze

Predicts sequences of eye fixations using transformers and semantic features from vision–language models. LogitGaze-Med applies this approach to medical imaging.

[![Code](https://img.shields.io/badge/Code-GitHub-334155?style=flat-square&logo=github&logoColor=white)](https://github.com/LvovDmitro/LogitGaze) [![Paper: ICLR 2025 workshop](https://img.shields.io/badge/Paper-ICLR_2025_%C2%B7_workshop-0F766E?style=flat-square)](https://openreview.net/forum?id=Om4j6IVb42) [![Paper: NeurIPS 2025](https://img.shields.io/badge/Paper-NeurIPS_2025-0F766E?style=flat-square)](https://proceedings.nips.cc/paper_files/paper/2025/hash/be7bc8aa38696723cebe296b6122d7e3-Abstract-Conference.html)

### Layout-aware document segmentation

Detects document elements, links figures to captions and generates descriptions with a vision–language model. The resulting document fragments are used for technical question answering.

[![Code](https://img.shields.io/badge/Code-GitHub-334155?style=flat-square&logo=github&logoColor=white)](https://github.com/mindlab-itmo/layout-aware-doc-segmentation) [![Paper: IEEE Access 2026](https://img.shields.io/badge/Paper-IEEE_Access_2026-0F766E?style=flat-square)](https://doi.org/10.1109/ACCESS.2026.3655813)

### EHR model selection

A coauthored study of why models with similar overall scores can prioritize different hospital episodes. We compare calibration, retraining stability and which episodes are selected as high risk. Public aggregates can be reproduced without patient records.

[![Code](https://img.shields.io/badge/Code-GitHub-334155?style=flat-square&logo=github&logoColor=white)](https://github.com/LvovDmitro/ehrshot-state-or-space) [![Paper: NeurIPS 2026 TAE workshop](https://img.shields.io/badge/Paper-NeurIPS_2026_%C2%B7_TAE_workshop-0F766E?style=flat-square)](https://openreview.net/forum?id=RffArnWpec)

### Prenatal risk scoreability

Coauthored work on how eligibility rules and referral capacity affect prenatal risk evaluation. The analysis uses CDC Natality data and a fixed model to separate these effects.

[![Code](https://img.shields.io/badge/Code-GitHub-334155?style=flat-square&logo=github&logoColor=white)](https://github.com/vache4ogan/prenatal-risk-scoreability)

### AI Dungeon Master

I contributed to a team project for running Dungeons & Dragons games with LangGraph and LangChain. Eight agents share game state and handle storytelling, world simulation, actions and rules.

[![Code](https://img.shields.io/badge/Code-GitHub-334155?style=flat-square&logo=github&logoColor=white)](https://github.com/ITMO-Agentic-AI/ai-dungeon-master)
